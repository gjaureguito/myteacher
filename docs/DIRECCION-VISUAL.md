# Dirección visual e imágenes editoriales

Se incorporan tres imágenes originales creadas con la herramienta integrada ImageGen, convertidas a WebP sin cambiar el contenido. No se usó CLI ni API key. Son escenas ilustrativas; no representan alumnos, personal o instalaciones de InglésPro ni de una universidad real. Esta condición aparece en los pies de imagen.

## Archivos y uso

- `public/assets/images/learning-together-v1.webp`: portada y vista previa social. Personas compartiendo una lectura; 1536×1024, aproximadamente 126 KB.
- `public/assets/images/reading-notes-v1.webp`: biblioteca y lectura destacada. Libro, cuaderno y lápiz; 1536×1024, aproximadamente 161 KB.
- `public/assets/images/reading-room-v1.webp`: programa. Sala de lectura ilustrativa; 1536×1024, aproximadamente 215 KB.

Se definen dimensiones para reservar espacio, textos alternativos descriptivos, prioridad alta para las imágenes iniciales y carga diferida para la imagen secundaria de portada. El encuadre cambia con el ancho de pantalla. La composición editorial conserva la identidad tinta/bordó/papel y ajusta tamaños, espacios y proporciones. No se cambian cursos, pagos ni registros.
